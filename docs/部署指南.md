# 前端部署指南

## 环境概述

- 部署方式：Docker Nginx 容器
- 宿主机：Windows (WSL2 Ubuntu-22.04)
- 卷路径：`/volume/OmniPavilion/nginx/html/`
- 容器映射：`/usr/share/nginx/html/`
- Nginx 端口：8050
- Nginx 配置：`/volume/OmniPavilion/nginx/nginx.conf`

## 部署步骤

### 1. 构建

在项目根目录执行：

```bash
npm run build
```

构建产物输出到 `dist/` 目录。

### 2. 部署到 WSL 卷

```bash
wsl -d Ubuntu-22.04 -u root bash -c "cp -r /mnt/d/Projects/project/OmniPavilion/Vue3/dist/* /volume/OmniPavilion/nginx/html/"
```

### 3. 清理旧模块（可选）

如果删除了某些模块，需要手动清理 Nginx 中对应的旧目录：

```bash
wsl -d Ubuntu-22.04 -u root bash -c "rm -rf /volume/OmniPavilion/nginx/html/src/english /volume/OmniPavilion/nginx/html/src/bibliophile /volume/OmniPavilion/nginx/html/src/template"
```

### 4. 验证

```bash
curl -s -o /dev/null -w "%{http_code}" http://localhost:8050/
# 应返回 301 → 重定向到 /application/
# 再访问任意模块确认返回 200
```

## 访问地址

| 模块 | 地址 |
|------|------|
| 导航首页 | http://localhost:8050/application/ |
| 文集 | http://localhost:8050/article/ |
| 音乐播放器 | http://localhost:8050/music/ |
| 日记 | http://localhost:8050/diary/ |

## Nginx 配置要点

- 根路径 `/` 重定向到 `/application/`
- 各模块通过 `rewrite ^/([^/]+)/.* /$1/index.html last` 路由
- 静态资源（assets）直接从 `/usr/share/nginx/html/assets/` 提供
- 404 指向 `/src/noFound/index.html`

## 备注

- 部署前请确保项目能成功构建（`npm run build` 无错误）
- WSL 卷中文件属主为 root，复制时需要 `-u root` 参数
- 如修改了 Nginx 配置，需要重启 Nginx 容器
